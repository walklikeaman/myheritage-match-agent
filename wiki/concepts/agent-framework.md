# Как устроена работа агентов в проекте

Схема пришла из набора «Схема проекта» 2026-11-13 и легла поверх того, что уже было (CLAUDE.md, вики, `.loops/`, `/ship`).

Слои, сверху вниз:

1. Инструкции проекта на claude.ai: как работать, одна жирная строка на правило.
2. [`docs/RULES.md`](../../docs/RULES.md): полный текст правил с датой и причиной.
3. [`CLAUDE.md`](../../CLAUDE.md): только то, что верно в этом репозитории (VIP-фамилии, лимит сессии, селекторы, раннер).
4. [`docs/agent-method.md`](../../docs/agent-method.md): ритуал старта, петля задачи, вики, автолог, `/ship`.
5. Вики (`wiki/`), уроки и запреты (`.loops/`), память проекта (что верно сейчас).

Как это крутится:

- Перед задачей поиск по знаниям: навык `mh-knowledge-lookup` (`search.sh 'слово|слово'`).
- После задачи запись обратно: страница вики, строка сверху в [журнале](../log.md), указатель в памяти.
- Задача заняла больше одной попытки или Никита поправил: навык `mh-harness-reflect`, урок в `.loops/experience.md`. Та же ошибка второй раз: запрет в `.loops/guardrails.md`.
- Конец работы: `/ship` (точечный `git add`, тест вики, коммит, push, draft PR).
- Механику вики ловит `python3 -m pytest -q tests/test_wiki.py`, в CI тоже.

Префикс навыков проекта: `mh`.
